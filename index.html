Sistema gerencial

Gerenciamento de Biblioteca

Desenvolvi um sistema de gerenciamento de biblioteca em PHP utilizando MVC. O sistema possui login, cadastro e gerenciamento de livros, alunos e autores, além do controle de empréstimos. Também implementei relacionamentos entre as tabelas para associar livros e autores, utilizando rotas, autoload, POO e CRUD completo. O projeto foi desenvolvido com foco na organização e separação das responsabilidades do sistema. Deslize a galeria para conhecer as telas.
